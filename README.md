# README

MkDocs generates a documentation in html format from markdown files. It is very easy to use.

## Quickstart

- **Linux:** On a debian-based linux distro run `install.sh`
- **Windows:** Run `install.bat` - You may need to chnage the Python version in the script (currently 3.9) 
- Then just execute the `run.sh` script
- The html site will be hosted in localhost and opened in a webbrowser


## Manual installation
https://www.mkdocs.org/user-guide/installation/

## Write the docs
- Just write your notes in markdown with your favorite editor (i.e. Typora, Apostrophe, VSCode)
- Save the file in docs in a proper subfolder
- Everthing inside docs is parsed automatically
