# Better cat (bat)

Better cat (bat) is so much more convinient for daily usage than cat, especially if your most side tasks are on a Linux / WSL2 shell.

- Install: `sudo apt install bat`
- Usage: batcat <large-file.xml>


## Usage tipps

- bat uses `cat | less` by default
- Ppen the context meni with :
- Search for strings with :/<search-expression>

## Tip

Alias batcat to bat to be faster on typing: alias bat="batcat".
Add this in your ~/.profile or ~/.bashrc (bash) or ~/.zprofile or ~/.zshrc (zsh).
I prefer having an custom ~/.aliasrc file which is sourced in ~/.zshrc.
